# Aqsa's Salon — Luxury Beauty & Care Website

An elite, production-quality, responsive luxury beauty salon web application built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and React Router.

## Design Direction & Visual Identity
- **Warm ivory**: `#F8F5F0`
- **Soft beige**: `#EAE2D8`
- **Dark espresso**: `#29231F`
- **Muted bronze**: `#A77B55`
- **Champagne**: `#D8BFA5`
- **Typography**: Playfair Display (Serif headings) & Inter (Sans-serif body content).

---

## Technology Stack
- **React 18** + **TypeScript**
- **Vite** (Lightning-fast bundling)
- **Tailwind CSS** (Utility-first styling with custom salon design tokens)
- **Framer Motion** (Editorial animations and smooth page transitions)
- **Lucide React** (Clean modern iconography)
- **React Router DOM** (Client-side multi-page routing)

## Getting Started & Installation

1. Navigate to the project directory:
   ```bash
   cd Aqsa-Salon-Website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```
